# 마영전 스펙 진단기

마비노기 영웅전 캐릭터가 원하는 던전에 들어가려면 어떤 스탯이 얼마나 모자란지 보여주고, 거래소 시세 기준으로 **가장 적은 골드로 부족분을 채우는 순서**를 계산하는 웹앱입니다.

## 실행

```bash
npm install
cp .env.example .env     # NEXON_API_KEY 입력 (비워 두면 목업 모드)
npm start                # http://localhost:3000
npm test                 # 계산 로직 테스트
```

API 키는 서버에만 두고, 브라우저는 이 서버의 `/api/*`만 호출합니다 (넥슨 Open API의 CORS·Origin 검증 때문).

## 화면 구성

- **던전 입장 조건**: 레이드·스페셜·기사단·붉은 달·시공간 왜곡의 빠른 전투 최소 입장 능력치를 낮은 순서로 쌓아 보여주고, 내 캐릭터가 어디까지 들어갈 수 있는지 선을 그어 표시합니다.
- **부족한 스탯**: 고른 던전 기준으로 스탯별 부족분과, 추천 경로를 마친 뒤 예상치.
- **가장 싸게 채우는 순서**: 매번 "부족분 1%를 메우는 데 드는 골드"가 가장 적은 다음 단계를 고르는 방식(탐욕법)으로 만든 성장 계획과 총비용, 필요한 재료.
- **스탯별 가성비 순위**: 스탯 1포인트에 드는 골드 비교.
- **재료 시세**: 거래소 중앙값 + 직접 입력값 (직접 입력이 우선).

## 계산에 들어가는 성장 방식 (`src/catalog.js`)

| 분류 | 내용 |
|---|---|
| 연마 | 에리우 무기(공격력·밸런스·크리티컬·파괴력 I/II), 에리우 헬름·건틀릿·그리브즈·메일, 와드네 부츠(방어력·파괴력 I/II) |
| 장신구 강화 | 필멸의 굴레, 풍요의 근본, 스타라이트 벨트, 침묵의 증표, 고요의 증표 (1~20강, 성공률·연속 실패 보너스 반영) |
| 승급 | 에리우 무기(일반~레어), 에리우 헬름·그리브즈·메일·건틀릿(일반~전설) |
| 인챈트 | 비극, 가득한, 물드는, 헤매는, 메마른, 초월, 강림 (기본값은 꺼짐) |

수치는 모두 공식 패치노트 기준이고 항목마다 출처 링크가 붙어 있습니다.

## 계산 방식과 가정

- 확률 강화는 **연속 실패 보너스(천장)까지 반영한 기대 시도 횟수 × 1회 비용**으로 계산합니다. 실패해도 단계는 유지된다고 가정했고, AP 소모는 넣지 않았습니다.
- 연마 **행운 성공(2배·3배)** 확률은 공개되지 않아 기본 배율 1(보수적)입니다. 화면에서 바꿀 수 있습니다. 파괴력 연마는 행운 성공이 적용되지 않습니다.
- **인챈트**는 성공 확률·파괴 위험이 비용에 들어가지 않고, 기존 인챈트를 덮어쓰기 때문에 기본으로 꺼 두었습니다.
- 정수처럼 **귀속이라 시세가 없는 재료**가 들어간 방법(승급 등)은 자동으로 빠지고 "시세 확인 필요"로 표시됩니다. 가격을 직접 넣으면(이미 가지고 있으면 0) 계산에 들어갑니다.
- 캐릭터를 불러오면 장비 API(`/character/item-equipment`)로 연마 수치·장신구 강화 단계·에리우 승급 등급·적용된 인챈트를 자동으로 채우고, 착용하지 않은 장비(예: 안 낀 반지)는 계산에서 뺍니다 (`src/equipment.js`). 연마의 '공격력 제한 해제'는 파괴력 I+II 합계로 오므로 I을 먼저 채운 것으로 나눠 계산합니다. 직접 입력한 스탯만 쓸 때는 장비 진행 상황도 직접 넣어 주세요.
- 정령석, 팔찌 보석, 타이틀, 버프 등은 아직 계산에 없습니다.

## 실제 API 연결 시 확인할 것

Open API 문서가 JS로만 렌더링되어 **캐릭터 스탯·거래소 응답 스키마는 아직 확인하지 못했습니다.** 그래서 두 군데를 느슨하게 만들어 두었습니다.

1. **엔드포인트 경로**: `.env`의 `NEXON_PATH_*` 값을 문서의 실제 경로로 맞추세요. `/id`(ocid 조회)만 확인된 경로입니다.
2. **응답 파싱**
   - 스탯: `src/stats.js`가 응답 안의 `{이름, 값}` 쌍을 찾아 한국어 스탯 이름으로 매칭합니다. 이름이 다르면 `STAT_ALIASES`에 추가하세요. `/api/character?name=캐릭터&raw=1`로 원본 응답을 볼 수 있습니다.
   - 거래소: `src/nexon.js`의 `PRICE_KEYS`(개당가) / `TOTAL_KEYS`+`COUNT_KEYS`(총액÷수량)에 실제 필드명을 넣으세요. 시세는 10분 캐시합니다.

## 데이터 업데이트

- 새 레이드가 나오면 `data/dungeons.json`에 패치노트의 "빠른 전투 최소 입장 능력치"를 한 항목 추가하면 됩니다. 2025-10-23 패치로 대항력→방어력 관통, 공격력 제한 해제→파괴력으로 이름만 바뀌었으므로 예전 수치도 그대로 `armorPen`/`destruction`에 넣습니다.
- 새 장비·연마·승급은 `src/catalog.js`에 같은 형식으로 추가합니다.

```

src/nexon.js         NEXON Open API 클라이언트, 거래소 시세 캐시, 목업
data/dungeons.json   던전 입장 조건
data/mock/           목업용 예시 데이터 (실제 시세 아님)
public/              화면
test/                계산 로직 테스트
```
